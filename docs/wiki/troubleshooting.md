# Troubleshooting

## Startup says that no approval channel is configured

Choose one of these fixes:

- Configure `LUCIFER_TELEGRAM_TOKEN` and pair a Telegram chat.
- Start from a configuration generated by `npx lucifer-gate --init .` so the
  Admin UI credential is present.
- Use `--auto-approve` only for development.

## Telegram does not show a request

Confirm that the bot token is correct, the target chat messaged the bot,
pairing wrote the intended chat ID, and the command matched `manual_approve`.
Also verify that the process can reach Telegram's API.

## The Admin UI returns unauthorized

Use the original admin secret printed by `--init`, not the hash or salt stored
in `lucifer.json`. For API calls, use:

```text
Authorization: Bearer YOUR_ADMIN_SECRET
```

Repeated invalid requests may be rate-limited.

## The Admin UI shows no pending request

Check that the command is still waiting, the page is connected to the same
server and port, and no other channel already decided it. Pending requests are
process-local and disappear after a restart.

## An approval does not apply later

Exact approvals do not cover a different command; prefix approvals cover only
the derived first two tokens; 2-hour and 8-hour approvals expire; approve-once
is never cached.

## The command timed out

The caller was not approved before `approvalTimeoutSeconds` elapsed. Inspect
the server and audit logs for channel errors or an unreachable approver, then
retry after correcting the channel.
